萃取表观去除率计算器 v0.8

用于 OpenChemProcess（OCP）萃取操作数据整理。计算对象是“以产品峰面积归一化后的杂质表观去除率”，不引入 HPLC 响应因子、真实质量平衡或水相数据。

离线单机版：支持 CSV 导入、手工输入、网页内计算、排序、整理结果CSV导出和离线格式化 .xls 导出；不依赖网络或外部 CDN。导入旧格式 CSV 时，会自动映射“样品/洗涤次数/产品面积绝对值/杂质面积绝对值”等表头，并按每个“0次/洗涤粗品”自动生成实验组ID。

单次表观去除率_n = 1 - [(杂质峰面积_n / 产品峰面积_n) / (杂质峰面积_{n-1} / 产品峰面积_{n-1})]；累计表观去除率_n = 1 - [(杂质峰面积_n / 产品峰面积_n) / (杂质峰面积_0 / 产品峰面积_0)]
