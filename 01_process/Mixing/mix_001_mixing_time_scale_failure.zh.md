# MIX-001｜混合时间尺度失效（非 Gate）

## 1. 定位

本文件用于标识一类在放大过程中容易被误判的控制失效情形：

在投料顺序正确（CHG-001）、  
滴加方式与名义滴加速率在逻辑上成立（CHG-002）的前提下，  
由于混合时间尺度不足，  
局部反应或相态历史在全局控制变量生效之前已经形成，  
并导致控制权发生逻辑层面的不可逆转移（logical lock-in）。

---

## 2. 核心区分：混合本体失效 vs 混合暴露问题

### A｜混合本体失效（Core Mixing Failure）

混合构成控制成立的必要前提。  
当混合时间尺度大于关键反应或物理变化的特征时间尺度时，  
局部历史在均化完成前被锁定，  
控制权无法通过后续操作恢复。

**判定特征**：

- 延长反应时间不构成有效修复；
- 调整滴加结构不构成有效修复；
- 仅通过混合层面的结构性改变方可避免失效。

---

### B｜混合暴露问题（Mixing as Manifestation）

混合并非问题的第一性根源。  
在放大条件下，混合能力变化改变了问题的暴露方式或发生概率，  
使潜在问题提前或集中显现。

**判定特征**：

- 通过治理根本原因可恢复控制权；
- 混合仅作为辅助手段，而非控制前提。

---

## 3. A 类案例｜混合本体失效（控制必然丧失）

### Case A1｜两相水解反应在放大条件下的路径锁死

**系统条件描述**

该体系中，底物溶解于有机相而不溶于水相；  
目标水解反应仅能通过有机–水相界面完成。  
在小试条件下，由于体系尺度小、能量输入密度高，两相界面更新速率充分，反应可在有限时间内完成。  
在放大条件下，反应器几何与搅拌特性发生变化，两相界面更新频率显著下降。

**放大后状态特征**

- 原料在有机相中的滞留时间显著延长；
- 已水解产物在碱性水相中的停留时间超过可接受窗口；
- 副反应随时间累积，且不可避免。

#### Decision Trace

**Hypothesis Space**

- H1：滴加结构或滴加速率问题（CHG-002）  
- H2：两相分布问题但可通过时间修复（PHS）  
- H3：混合时间尺度失效（MIX-001）

**Elimination Path**

- 调低滴加速率未能恢复主反应路径 → 排除 H1；  
- 延长反应时间导致副反应持续放大 → 排除 H2。

**Decision Pivot**

确认界面反应在混合均化完成之前已发生，  
局部反应历史一旦形成即对整体结果产生决定性影响，  
控制权不可恢复。

**Explicit Labels**

- MIX-001: true  
- Recoverable_by_time: false  
- Recoverable_by_dosing: false  

---

### Case A2｜要求瞬时分散的滴加体系在放大中的失效

**系统条件描述**

该体系对局部浓度高度敏感，  
要求滴加物料在进入反应体系后于极短时间尺度内完成空间均化。  
该前提在小试条件下默认成立。

**放大后状态特征**

- 即使采用极低滴加速率，副反应仍在加料初期发生；
- 副反应的发生时间早于混合完成时间。

#### Decision Trace

**Hypothesis Space**

- H1：滴加速率仍然偏高（CHG-002）  
- H2：混合时间尺度不足（MIX-001）

**Elimination Path**

- 进一步降低滴加速率未能抑制副反应；  
- 延长反应时间导致副反应比例上升。

**Decision Pivot**

副反应在混合完成之前发生，  
局部浓度历史不可逆。

**Explicit Labels**

- MIX-001: true  
- Recoverable_by_time: false

## 4. B 类案例｜混合暴露问题（根因在别处）

### Case B1｜BF₃ 络合催化体系中的局部高活性暴露

**系统条件描述**

该反应采用 BF₃ 络合物作为催化试剂。  
在工艺实施中，该 BF₃ 络合催化剂以高有效浓度（近似纯品）的形式加入反应体系。  
小试条件下，由于体系尺度小、混合充分，催化活性在空间上能够迅速均化。  
放大条件下，催化剂在加入初期出现局部瞬时高活性区域。

#### Decision Trace

**Hypothesis Space**

- H1：混合时间尺度失效（MIX-001）  
- H2：催化剂加入结构导致的局部活性密度过高（CHG-002）

**Elimination Path**

- 降低催化剂加入速率或对催化剂进行预稀释后，反应路径完全恢复 → 排除 H1。

**Decision Pivot**

控制权可通过催化剂加入结构与等效浓度的调整恢复。

**Explicit Labels**

- MIX-001: false  
- CHG-002: true  

---

### Case B2｜盐酸酸化过程中有机酸析出路径偏移（oil-out）

**系统条件描述**

该工艺通过滴加盐酸，使体系中的有机盐转化为游离有机酸并以固体形式析出。  
在小试条件下，酸化速率与成核/固化速率匹配，目标产物能够稳定析晶。  
在放大条件下，盐酸局部进入速率显著提高，体系酸化速率超过有机酸成核与固化速率。

#### Decision Trace

**Hypothesis Space**

- H1：混合时间尺度失效（MIX-001）  
- H2：相态转化与析出路径问题（PHS / CRY）

**Elimination Path**

- 通过降低盐酸滴加速率、改善酸的空间分布后，析出路径由油状中间相转回固体析晶 → 排除 H1。

**Decision Pivot**

混合影响的是相态转化路径的暴露方式，  
而非决定成核/析出的第一性动力学。

**Explicit Labels**

- MIX-001: false  
- Primary_driver: Phase / Crystallization  

---

## 5. 使用提示

- 当案例符合 A 类结构时，应优先从混合本体层面进行治理；
- 当案例符合 B 类结构时，应首先倒推根本原因，再评估混合作为辅助手段的必要性；
- 不应仅基于表观现象将问题归类为 MIX-001。

---

#Audit: 属于混合控制权逻辑锁死型风险；其识别依赖于对失败后“控制权是否仍可通过时间或滴加结构恢复”的判读过程，而非单一现象判断。
若混合时间尺度失效已导致路径或局部反应不可逆展开，后续温度调整仅能延迟后果，不能恢复控制权；此类情形不应归类为 thermal control authority（参见 THR-001）。
